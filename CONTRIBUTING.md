# Contributing

Thanks for helping improve Agents Usage.

- Keep each change focused and explain its purpose in the pull request.
- Check that the change does not break existing behavior, and add or update tests when practical.
- Run `cargo test --locked`, `cargo clippy --locked -- -D warnings`, and `./tools/selftest.py` before submitting.
- If an AI agent assisted with the contribution, disclose the agent or tool by name and briefly describe its role in the pull request.

By contributing, you agree that your work is provided under this repository's license.
